# PhotoCheck

`plan.md`와 2026-10-08에 변경한 사용자 검증 기준에 따른 Windows 64비트용 수험생 사진 검수 프로그램입니다. PySide6 화면과 Pillow 파일 검사, MediaPipe 얼굴 분석, PP-OCRv3 문자 후보 검출 및 Korean PP-OCRv5 연속 글자 수 검사의 CPU 로컬 분석을 사용합니다. 실행 시 인터넷이나 별도 모델 설치가 필요하지 않습니다.

## 실행

배포 파일은 `dist/PhotoCheck_0.1.0.exe`입니다. 빌드 파일명은 `PhotoCheck_버전.exe` 형식이며 `photocheck/__init__.py`의 `__version__`을 사용합니다. **이 파일 하나만 복사하면 Python 설치와 관리자 권한 없이 실행할 수 있습니다.** 더블 클릭 후 사진 폴더를 선택하고 **검사 시작**을 누르세요. 기본 목록에는 확인 필요·파일 오류만 표시합니다. 검색과 사유 필터를 적용한 목록을 기준으로 이전·다음 버튼 또는 목록/미리보기 영역의 좌우 키로 이동합니다. 사진은 화면 맞춤, 확대·축소, 마우스 휠 확대, 드래그 이동을 지원합니다. 분석 표시를 켜면 얼굴 검출 영역과 눈·코·턱 등의 얼굴 특징점을 볼 수 있습니다.

취소하면 현재 파일 처리가 끝난 뒤 중단하며 처리된 결과를 유지합니다. 미처리는 정상으로 집계하지 않습니다. 새 검사는 이전 결과와 정상 재분류를 초기화합니다. **결과 저장**은 확인 필요·파일 오류만 엑셀(.xlsx)로 저장하며 자동 정상과 사용자가 정상으로 재분류한 사진은 제외합니다. 검색·필터와 관계없이 현재 검사에서 남은 모든 확인 대상을 저장합니다. 엑셀 설치 없이도 저장할 수 있습니다.

우측 사진 아래의 **정상으로 분류** 버튼은 현재 표시된 사진을 정상으로 변경하고 목록·건수를 갱신합니다. 원래 분석 사유와 검사 기준은 내부 결과에 유지합니다. 미리보기를 불러오지 못했거나 검사·복사 중일 때는 재분류할 수 없습니다. 재분류는 현재 실행의 검사 결과에 반영되며 프로그램 종료나 새 검사 이후까지 복원하지 않습니다.

**사진 복사** 버튼은 버튼을 누른 시점에 검색·필터로 목록에 표시된 사진들을 선택한 폴더로 복사합니다. 상대 경로의 하위 폴더 구조를 유지해 다른 폴더의 같은 파일명을 구분하며 원본과 기존 사본은 덮어쓰지 않습니다. 같은 경로에 파일이 있으면 제외하고 복사 실패는 별도로 안내합니다. 복사는 별도 작업 스레드에서 수행하며, 창을 닫으면 복사를 중단하고 작성 중인 사본을 제거합니다. 정상으로 재분류한 사진은 복사 대상에서 제외됩니다.

화면 오른쪽 위의 **톱니바퀴 버튼**에서 검사 기준을 설정합니다. 기본 검사·정면 검사·재촬영 검사·글자 검사 탭에서 항목을 켜거나 끄고 기준값을 수정할 수 있습니다. **저장**을 누르면 다음 검사부터 적용되고, **취소**는 변경을 버립니다. **기본값 복원**도 저장하기 전에는 적용되지 않습니다. 검사 진행 중에는 설정 버튼을 사용할 수 없습니다. 파일 손상·얼굴 미검출·여러 얼굴·분석 오류 등 기본 유효성 확인은 항상 수행합니다.

**증명사진 가로·세로 비율**은 기본 검사 탭에서 설정합니다. 기본 기준은 가로:세로 **3:4**, **허용 오차 비율 0.5**입니다. 사진의 가로를 기준 가로 3에 맞춰 환산하고 **환산 세로−가로**를 비교합니다. 기준 차이는 4−3=1이므로 **0.5~1.5**를 허용합니다. 이는 가로 3일 때 세로 **3.5~4.5**에 해당합니다. 300×350과 600×700은 같은 차이 0.5로 통과하며 200×300은 차이 1.5로 통과합니다. 200×301은 차이 1.515로 확인 필요입니다. 양쪽 경계값은 허용합니다. EXIF 방향을 반영한 원래 표시 해상도로 계산하며 픽셀 차이를 직접 비교하거나 백분율로 판정하지 않습니다. 기준 가로·세로, 허용 오차 비율, 검사 여부를 수정할 수 있습니다. cm나 DPI 또는 특정 픽셀 해상도를 강제하는 검사는 아닙니다.

일반적인 3.5:4.5 비율도 기본 설정을 통과합니다. 이 앱의 비율 검사가 전체 여권 제출 규정을 검증하는 것은 아닙니다. 이전 0.5·0.6·0.7 버전의 설정 파일은 다른 사용자 기준과 검사 여부를 유지하며 읽습니다. 0.5·0.6의 백분율 허용 오차는 새 단위의 기본값 **0.5**로 교체하며, 0.7의 허용 오차 비율은 그대로 유지합니다. 글자 검사에는 새 기본값을 추가합니다. 5%를 새 단위의 5로 해석하지 않습니다. 읽을 때 기존 파일은 바꾸지 않고 다음 저장 시 최신 형식으로 기록합니다.

설정은 실행 파일 위치와 무관하게 `%LOCALAPPDATA%\PhotoCheck\settings.json`에 저장됩니다. 다시 실행하면 복원하며, 파일이 손상되거나 읽을 수 없으면 안내하고 기본값을 적용합니다. 저장 실패 시 팝업에서 오류를 안내하며 이전 설정을 유지합니다. 이미 검사한 결과의 기준은 바뀌지 않습니다. 결과별 설정은 내부 검사 결과에 유지하며 엑셀에는 파일명과 판정사유만 기록합니다.

## 개발 환경

개발·빌드는 Python 3.12 / Windows 11 64비트를 사용합니다. 사용자 PC에 Python을 설치할 필요는 없습니다. Qt의 Windows 기본 ICU API를 사용하므로 Windows 10 1903 이상을 대상으로 합니다. Windows 10 별도 PC 호환성 검증은 남아 있습니다.

```powershell
py -3.12 -m venv .venv312
.\.venv312\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv312\Scripts\python.exe tools\download_models.py
.\.venv312\Scripts\python.exe main.py
```

```powershell
.\.venv312\Scripts\python.exe -m pytest -q
.\.venv312\Scripts\python.exe main.py --smoke-test build-smoke.json
powershell -ExecutionPolicy Bypass -File build.ps1
```

`--smoke-test <보고서 경로>`는 개발·배포 검증용 옵션입니다. Qt 창 생성, 내장 얼굴 모델 두 개 로딩, 한글 임시 경로의 실제 작업 스레드 검사, 건수 집계, 검색, 미리보기를 검사한 뒤 지정된 JSON 보고서와 화면 이미지를 생성합니다. 일반 실행은 보고서를 만들지 않습니다. 빌드 스크립트는 실행 파일 하나를 프로젝트 밖의 한글·공백 경로에 복사하고 개발 환경 경로를 제거한 상태에서 이 검증을 수행합니다. 모델은 실행 파일에 포함되고 프로그램은 다운로드 코드를 호출하지 않습니다. 모델 다운로드 도구는 개발 시에만 사용하며, 버전 1 URL과 SHA-256 해시를 고정합니다.

## 권한과 배포 검증

프로그램 화면은 Windows 시스템의 밝게/어둡게 설정과 관계없이 밝은 테마로 표시합니다. 표 제목, 검색창, 콤보 목록, 진행 표시줄과 활성·비활성 버튼에 일관된 색상을 적용합니다. 개발 시 `tools/preview_theme.py`로 어두운 초기 색상 설정에서 대기·검사 중·콤보 목록 화면을 확인할 수 있습니다.

실행 시 내부 파일은 `%LOCALAPPDATA%\PhotoCheck\Runtime` 아래에 풀립니다. 실행 파일이 있는 폴더에 쓰기 권한이 없어도 실행되며, 기본 TEMP/TMP 경로가 잘못되어 있어도 해당 사용자 데이터 경로를 사용합니다. 이 사용자 데이터 폴더에는 쓰기 권한이 필요합니다. 읽기 권한이 없는 사진은 파일 오류로 표시하고 접근할 수 없는 하위 폴더는 따로 안내합니다. 검사 시작 폴더에 접근할 수 없으면 기존 검사 결과를 유지합니다.

결과 저장 창은 기본적으로 사용자 문서 폴더의 `사진검수_결과.xlsx`를 제안합니다. 저장 금지 폴더, 읽기 전용 파일, 다른 프로그램이 잠근 엑셀 파일은 오류를 안내하며 검사 결과와 기존 파일을 유지합니다. 새 엑셀은 같은 폴더의 임시 파일에 작성한 뒤 완성된 파일로 교체합니다. 원본 사진 경로에 결과를 덮어쓸 수 없습니다. 파일명과 사유는 엑셀의 문자열 셀로 저장하여 수식으로 실행되지 않습니다. 첫 행 고정·자동 필터·열 너비를 제공하며, 정상 건만 있는 경우 제목 행만 저장합니다. 별도 실행 환경을 추가하지 않는 표준 라이브러리의 XLSX 작성기를 사용합니다.

`tools/verify_exe.py`는 개발 Python 경로를 제거하고 기본 TEMP/TMP를 잘못 지정한 조건에서 임시 생성 이미지만으로 검사·엑셀·복사·정상 재분류를 검증합니다. `tools/verify_review_permissions.py`는 임시 생성 JPEG로 Windows 실제 권한 차단과 파일 잠금을 검사합니다. 이번 변경에서는 사용자 요청에 따라 샘플 사진 검사를 수행하지 않았습니다. 이전의 전체 샘플 진단 도구 `tools/validate_distribution.py`는 명시적으로 실행하는 경우에만 sample 전체를 검사합니다. 내장 Python DLL 경로도 확인하며 별도의 Python 미설치 실물 PC 또는 Windows 10의 검증을 대신하지 않습니다.

```powershell
.\.venv312\Scripts\python.exe tools\validate_distribution.py
```

분석 엔진은 별도 프로세스에서 동작합니다. 네이티브 분석 오류나 20초 응답 시간 초과는 해당 사진을 확인 필요로 남기고, 다음 파일에서 엔진을 다시 시작합니다. 현재 기준에서는 신체 모델과 분할 마스크를 사용하지 않습니다.

## 검사 기준과 한계

모든 필수 검사가 통과해야 정상입니다. 파일 접근·빈 파일·실제 JPEG/PNG 형식·전체 디코딩·확장자 일치·단일 프레임을 확인합니다. 투명 영역이나 다중 프레임은 확인 필요입니다. GIF/BMP/TIFF/WebP/HEIC 등의 후보도 수집하지만 초기 분석 지원 형식이 아니면 파일 오류로 표시합니다. 비이미지 제외 건수는 화면에 안내합니다. 폴더 접근 실패는 완료 상태와 툴팁에 표시합니다. 심볼릭 링크 디렉터리는 순환·폴더 범위 확대를 피하기 위해 탐색하지 않습니다.

검사와 미리보기 모두 EXIF 방향을 반영합니다. 원본은 쓰기 모드로 열지 않으며 회전·이동·삭제하지 않습니다. 전체 디코딩 후 분석용 사본을 최대 1280px, 미리보기를 최대 2200px로 줄입니다. 4천만 픽셀 초과 파일은 메모리 보호를 위해 확인 필요로 분류하고 미리보기 대신 안내합니다. 이것은 별도 제출 크기 규정이 아닙니다.

기본 회전·구도 기준은 다음과 같습니다. 아래 선택 검사의 수치는 톱니바퀴 버튼에서 수정할 수 있습니다. 해상도와 표시 방향은 EXIF를 반영한 사진을 기준으로 합니다.

- 실제 사진 해상도의 가로가 세로보다 넓으면 확인 필요입니다. 정사각형은 이 조건에 해당하지 않습니다. 분석용 축소 과정에서 해상도가 반올림되더라도 실제 가로·세로로 판단합니다.
- 정방향 얼굴 검출이 실패했을 때만 180도 회전 검출을 시도합니다. 회전 후 검출되면 회전 의심으로 확인 필요이며, 양쪽 모두 검출되지 않으면 판단 불가로 확인 필요입니다. 90도·270도 비교는 하지 않습니다.
- 얼굴 높이 비율은 사진 안의 얼굴 검출 사각형 높이 / 사진 높이입니다. **25% 이하(정확히 25% 포함)**이면 확인 필요입니다. 얼굴 크기 상한은 없습니다. 이 비율은 내부 분석 수치에 기록하며 엑셀에는 내보내지 않습니다.
- 양쪽 눈을 잇는 선의 기울기 절댓값이 **5도 이상(정확히 5도 포함)**이면 확인 필요입니다. 양쪽 눈의 가로 간격이 사진 너비의 10% 미만인 경우도 방향 판단 불확실로 처리합니다.
- 어깨·가슴·목·상체 특징점이나 영역을 검출하지 않아도 됩니다. 상체 검사에 쓰던 `pose_landmarker_lite.task` 모델은 배포 대상에서 제외했습니다.
- 얼굴 검출 점수(`face_confidence`)가 **0.8 이하**이면 확인 필요입니다. 반올림 전 점수로 판정하므로 정확히 0.8은 포함하고 0.8 초과는 이 조건을 통과합니다. 얼굴 특징점 검출 실패 등 다른 조건은 계속 적용합니다.
- 이마·턱 등 얼굴 특징점이 화면 가장자리 **2.5% 이내**에 있으면 경계 근접으로 확인 필요입니다. 좌표 2.5%·97.5% 경계도 포함합니다. 기존 이마 10%·턱 67%·얼굴 너비 15% 조건은 제거했습니다. 머리/턱 여백은 얼굴 특징점으로 확인하며 머리카락 영역의 분할 분석은 수행하지 않습니다.
- 얼굴 높이 부족과 이마·턱·눈·코·입·볼의 경계 근접 사유를 구분하고 실제 비율을 표시합니다. 기울기, 정면 여부, 중앙 위치, 얼굴 수·신뢰도와 얼굴 검출/특징점 위치 일치 조건은 유지합니다.

경계값·검출 실패·개별 분석 오류는 정상으로 통과시키지 않습니다. 한 파일의 예외는 다른 파일 검사를 중단시키지 않습니다.

인화사진 재촬영 의심 검사는 이미 읽은 분석 사본을 최대 384px로 축소해 사용합니다. 얼굴 위의 긴 테두리로 빠르게 후보를 선별한 뒤, 후보만 직선 결합으로 상세 검사합니다. 얼굴을 둘러싼 종이 테두리 3면, 두 면의 안팎 색 차이, 종이 바깥 배경의 명암 변화가 함께 확인되어야 확인 필요로 분류합니다. 단순 흰 테두리나 균일한 편집 배경만으로 분류하지 않습니다. 기본값은 종이 면적 15~85%, 최소 테두리 길이 사진 너비의 25%, 안팎 색 차이 3, 외부 배경 명암 변화 12입니다. 색 차이는 RGB 채널의 중앙값 차이 중 최댓값이며 배경 명암 변화는 회색조 90백분위−10백분위입니다. 양쪽 모두 0~255 범위입니다.

이 검사는 추가 학습 모델 없이 작동하는 휴리스틱입니다. 테두리가 잘린 사진, 균일한 바깥 배경, 테두리가 약하거나 기울어진 종이에서는 놓칠 수 있고, 실제 재촬영이 아닌 편집된 사진도 의심 대상으로 잡힐 수 있습니다. 자동 확정 대신 확인 대상으로 제시합니다. `128100020.jpg`는 기본 설정에서 재촬영 의심으로 분류됩니다.

사진 내 글자 검사는 **신뢰도 0.60 이상인 글자가 최소 3개 연속해서 인식될 때** 확인 필요로 분류합니다. 한글·영문·숫자를 세며, 공백·기호 또는 낮은 신뢰도의 글자에서 구간을 끊습니다. 별도 영역의 글자 수를 더하지 않습니다. 같은 글자가 반복되어도 각각 인식되면 세며, CTC의 반복 출력 프레임은 글자 하나로 처리합니다. 글자 내용은 화면·엑셀·보고서에 저장하지 않습니다.

PP-OCRv3/OpenCV로 전체 사진의 후보 영역을 찾고, 후보가 있을 때만 Korean PP-OCRv5/ONNX Runtime CPU로 연속 글자 수를 확인합니다. Paddle 실행 환경은 포함하지 않습니다. 기본 후보 검출 기준은 신뢰도 **0.60**, 최소 영역 높이 **사진 높이의 0.8%**, 분석 사본 최대 길이 **512px**입니다. 작은 원본은 전체 사진을 확대하지 않지만 모델 입력은 32px 단위로 조정합니다. 영역 점수는 글자 사이 빈 공간을 포함한 회전 사각형 평균입니다. 인식용 후보 사본은 높이 48px, 너비 최대 640px로 제한합니다. 후보가 64개를 넘으면 검사를 생략해 정상으로 통과시키지 않고 직접 확인하도록 안내합니다. 글자 검사는 얼굴 검출과 독립적이며 주황색 상자로 위치를 표시합니다.

톱니바퀴의 글자 검사 탭에서 활성화, 최소 연속 글자 수(3~30), 글자별 인식 신뢰도, 후보 검출 신뢰도·높이·분석 길이를 수정할 수 있습니다. 검출·인식·얼굴 점수는 서로 다른 수치입니다. 옷·배경의 글자도 검사합니다. 작거나 흐리거나 잘린 글자, 심하게 기울어진 글자, 필기체를 놓치거나 무늬를 글자로 오인할 수 있습니다. 3글자라도 모델이 읽지 못하면 이 조건으로 잡히지 않습니다. 샘플 `71W298095.jpg`의 좌측 하단 필기체는 새 기본값에서도 검출됩니다.

기준은 `photocheck/criteria.py`의 `Criteria`와 판정 규칙에 정의되어 있으며 버전은 `strict-0.9-text-runs-unvalidated`입니다. 이전 0.8 설정의 수치는 유지하고 새 연속 글자 수·인식 신뢰도 기본값을 추가합니다. **샘플에는 정답 표시가 없어 정확도와 오판정률을 측정할 수 없습니다.** 얼굴 기울기·정면·여백에 대한 추정은 휴리스틱이며 자동 정상도 최종 제출 적합성을 보장하지 않습니다. 얼굴 모델 점수는 적합 확률이 아닙니다. 기준 조정용·최종 평가용 표본을 분리하여 부적합의 정상 통과 건수, 정상 판정 정확도, 확인 대상 비율을 측정해야 합니다. 픽셀 제출 규정, 배경색, 복장, 동일인 여부 등은 검사하지 않습니다.

테스트는 손상·빈 파일·확장자 불일치·미지원·애니메이션·EXIF 8방향·한글 경로·원본 해시 보존·개별 판정 게이트·구도와 회전 불확실 사례·글자 영역 검출·필터 탐색·오래된 미리보기 응답을 다룹니다. 모델 통합 검증은 로컬 실제 추론을 사용하지만 표본 정확도 평가를 대신하지 않습니다. 샘플 처리와 원본 해시 보존, 검증 시점의 사진 건수와 시간을 TEST_RESULTS.md 및 build/sample-frozen.json에 기록합니다. Python 미설치 별도 PC와 Windows 10, 해당 PC의 보안 프로그램 차단 여부는 별도 검증이 필요합니다.

## 모델과 출처

MediaPipe는 `0.10.21`로 고정합니다. 샘플 장기 검사 중 `0.10.35`에서 통계 전송 시도 로그가 관측되어 로컬 실행 요건에 맞게 교체했습니다. 관련 보고는 [MediaPipe 이슈 #6291](https://github.com/google-ai-edge/mediapipe/issues/6291)에 있습니다. 모델은 동일한 로컬 파일을 사용합니다.

- [MediaPipe Face Detector](https://developers.google.com/edge/mediapipe/solutions/vision/face_detector): BlazeFace short range float16 v1
- [MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker): float16 v1
- [OpenCV Zoo PP-OCRv3](https://github.com/opencv/opencv_zoo/tree/47534e27c9851bb1128ccc0102f1145e27f23f98/models/text_detection_ppocr): PaddlePaddle 문자 후보 검출 모델, 2,423,490바이트, Apache 2.0.
- [PaddlePaddle Korean PP-OCRv5 mobile recognition](https://huggingface.co/PaddlePaddle/korean_PP-OCRv5_mobile_rec_onnx/tree/5c6f574b8e2230adf4287b33e736d71b9fabd28e): 연속 글자 수 확인용 인식 모델 13,418,787바이트와 문자 사전 71,345바이트, Apache 2.0. 공식 설정의 사전만 UTF-8 JSON으로 변환합니다. ONNX Runtime CPU와 사전까지 내장합니다.

배포에는 사용하지 않는 MediaPipe Solutions용 손·자세·홍채 모델, 영상용 FFmpeg, Qt PDF·가상 키보드·QML, AVIF 코덱과 별도 ONNX C-API DLL을 제외합니다. 얼굴 분석이 직접 참조하는 OpenCV DLL, NumPy 계산 모듈, Qt 소프트웨어 그래픽 대체 기능은 유지합니다. `tools/verify_compact_archive.py`는 실제 실행 파일의 제거 목록과 나머지 바이너리의 직접·지연 DLL 참조를 확인합니다. 축소 전 실행 파일의 용량 기록으로 비교하며 이전 실행파일 사본은 임시 파일 정리 시 삭제했습니다.

이전 버전의 Pose Landmarker는 현재 검사와 배포물에서 제외했습니다.

파일 URL·용량·해시는 `models/manifest.json`에 기록됩니다. MediaPipe Apache 2.0 라이선스와 배포 의존성 고지는 `licenses/`에 포함됩니다. PySide6는 LGPLv3를 포함한 라이선스로 배포되며 최종 상용 배포 시 관련 조건을 확인해야 합니다.

기본 창 크기는 1024×1000이며 목록과 사진 영역 너비를 1:1로 배치합니다. 설정 버튼은 취소 버튼 오른쪽에 있으며 제목 아래 안내 문구는 제거했습니다. 사진 아래에 이전·정상으로 분류·다음·분석 표시 버튼을 두고, 그 아래에 파일명과 페이지를 표시합니다. 사진 영역 우측 하단의 아이콘은 화면 맞춤이며, 마우스 휠로 확대·축소할 수 있습니다. 목록 하단 건수와 설명은 표시하지 않습니다.

엑셀 결과는 **파일명·판정사유** 두 열만 저장합니다. 화면의 검사 상태 문구와 확인 대상 목록 라벨은 제거했으며 파일명 컬럼 너비는 기존보다 약 10% 줄였습니다. 사진 복사 경로를 선택하면 취소 가능한 진행 팝업을 표시하고, 완료·중단 시 복사·제외·실패 건수를 알림으로 표시합니다.
